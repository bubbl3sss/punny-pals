
# PunnyPals

PunnyPals is a playful, clever, and adorable AI-powered **pun generator** using **Gemini 3 API**.  
Enter any word or short phrase, and watch Gemini 3 turn it into **3 witty, emoji-rich puns** with fun explanations. It’s cute, smart, and demonstrates AI creativity in a lighthearted, interactive way.

## Features
- Generate 3 puns per word or phrase  
- Explanation for each pun so anyone can understand the joke  
- Cute emojis and playful style  
- Supports English and bilingual inputs (Bengali + English)

## How It Works
PunnyPals uses **Gemini 3** to:  
1. Understand the user’s input word or phrase  
2. Generate 3 clever puns  
3. Add playful emojis  
4. Explain why each pun is funny  

This demonstrates Gemini 3’s **core reasoning, creativity, and language understanding** in a fun, engaging, and instantly demoable way.
